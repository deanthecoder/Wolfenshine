# Wolfenstein 3D game data

For the simplest setup, [download `w3d-box.zip` from DOS Games Archive](https://www.dosgamesarchive.com/file/wolfenstein-3d/w3d-box) and place the intact archive in this directory. Do not rename or extract it. The build extracts its eight required `.WL1` files automatically.

Alternatively, place either the eight extracted `.WL1` shareware files or the eight original `.WL6` full-game files here. A complete `.WL6` set takes priority when both editions are present.

The setup options and required filenames are listed in the [project README](../../README.md#quick-setup-with-the-free-shareware-episode).

All files placed here are ignored by Git except for this instruction file.
